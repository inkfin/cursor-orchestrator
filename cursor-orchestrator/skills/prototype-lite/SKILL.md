# Prototype lite

Use only when the deliverable is disposable evidence, not product code.

1. State the decision the prototype must inform and the observation that will answer it.
2. Declare the scratch or temporary paths before writing. The parent may write only there; existing product paths remain read-only.
3. Try one small version, or 2–3 side-by-side variants when comparison is useful. Keep dependencies and abstractions disposable.
4. Run the minimum observation needed and report what happened, including inconclusive results.
5. Discard, redirect, or promote deliberately. Promotion is a new formal task: rewrite **Scope**, **Owned paths**, and **Verification**, then hand product-code work to `fixer` or `designer`.

No production-grade tests, independent verifier, full recon, or verification plan is required for the throwaway artifact. Record a one-sentence exemption reason. Local only; leaf agents do not delegate.
